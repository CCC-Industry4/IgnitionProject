# MQTT Engine

Link to official documentation: [Link](https://docs.chariot.io/display/CLD80/MQTT+Engine)

---

1. MQTT Engine

    - The MQTT Engine is a plugin for Ignition that enables the use of the [MQTT](https://en.wikipedia.org/wiki/MQTT) network protocol.
    - It is used in the project to so that the Ignition Seerver (CSCI4X.com) can act as a broker for the Smart Homes. 

2. Common Erorrs

    - The Smart Homes may throw up the "MQTT Failed! Retrying" error. Common solutions include:
        - Restart the home using the reset button on the circuit board.
        - Restart the home, while holding pushbuttons one and two. This puts the home into setup mode so you can adjust the settings for the smart home. Follow [these instructions](https://github.com/CCC-Industry4/StarterGuide/blob/main/06_configure_smart_home.md).
